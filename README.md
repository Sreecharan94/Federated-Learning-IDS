# Federated Learning Based Intrusion Detection System (FL-IDS)

## 📌 Project Overview
This project is a Final Year B.Tech Capstone Project (2022–2026) at Alliance University.

The system implements a privacy-preserving Intrusion Detection System (IDS) using Federated Learning for real-time network traffic analysis.

---

## 🚀 Key Features
- Federated Learning based training
- Real-time intrusion detection
- LSTM + Multi-Head Attention architecture
- Apache Kafka live streaming
- Streamlit SOC Dashboard
- Privacy-preserving architecture
- Multi-class attack classification
- CICIDS2018 dataset integration

---

## 🛠 Technologies Used
- Python 3.10
- TensorFlow / Keras
- Apache Kafka
- Docker
- Streamlit

- Pandas
- Scikit-learn
