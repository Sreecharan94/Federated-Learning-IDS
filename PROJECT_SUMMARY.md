# FL-IDS Enterprise: Federated Learning based Intrusion Detection System

## Project Overview

**FL-IDS Enterprise** is a privacy-preserving, real-time intrusion detection system that leverages federated learning to detect network attacks without sharing sensitive data between participating organizations. The system combines LSTM-Attention deep learning models with Kafka-based streaming for scalable, enterprise-ready security monitoring.

### Key Features

- **Privacy-Preserving**: No raw data sharing between clients
- **Real-Time Processing**: Kafka-based streaming ingestion
- **Federated Learning**: Distributed training across multiple clients
- **Advanced Architecture**: LSTM + Multi-Head Attention model
- **Enterprise Ready**: Scalable, modular, and production-oriented
- **Comprehensive Monitoring**: Real-time dashboard and analytics
